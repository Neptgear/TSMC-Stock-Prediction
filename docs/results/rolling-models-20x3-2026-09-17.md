# TSMC 20 區間 × 3 種子模型測試

## 測試目的

檢查縮小版 Transformer 與 TFT-style 是否能在最近 20 個互不重疊的四日區間中，穩定低於「最後收盤不變」基準 MAE 49.22。

預先定義的通過規則是：同一模型的種子 11、42、97 都必須低於 49.22。另以成對 bootstrap 95% 信賴區間檢查改善是否清楚異於零。

## 防止資料洩漏

- 每個區間只提供截止日以前的行情、特徵與縮放資料。
- 後四個交易日只用於評分；交易日排程可以提供，但不提供未來價格。
- 20 個評分區間互不重疊。
- 每次模型都從頭訓練，並使用截止日前驗證集 MAE 選擇 checkpoint。
- 完整行情只下載一次；訓練函式每次只能取得各自截止日前的切片。

## 設定

| 項目 | 數值 |
| --- | --- |
| 區間 | 20 個互不重疊四日區間 |
| 每模型訓練次數 | 60（20區間 × 3種子） |
| 兩模型合計 | 120次訓練、480筆預測 |
| 種子 | 11、42、97 |
| epochs | 4 |
| 截止日全資料 refit | 2 epochs |
| d_model | 32 |
| 模型選擇 | 驗證集 MAE |
| Transformer loss | Huber |
| 比較基準 | 最後收盤不變，MAE 49.2187 |

這是縮小模型的篩選設定，用來判斷是否值得進行更昂貴的完整訓練；不能直接與先前 12 epochs、d_model 64 的單週測試視為同一模型容量。

## 結果

| 模型 | 種子 | MAE | RMSE | 相對基準 MAE 差 | 成對 bootstrap 95% CI | 低於49.22 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| Transformer | 11 | 49.01 | 66.53 | -0.21 | [-1.14, +0.74] | 是 |
| Transformer | 42 | 49.13 | 66.53 | -0.09 | [-2.04, +1.84] | 是 |
| Transformer | 97 | 48.82 | 66.48 | -0.39 | [-1.64, +0.85] | 是 |
| TFT-style | 11 | 48.61 | 65.74 | -0.61 | [-1.74, +0.49] | 是 |
| TFT-style | 42 | 49.25 | 66.72 | +0.03 | [-0.83, +0.89] | 否 |
| TFT-style | 97 | 49.05 | 66.44 | -0.17 | [-1.47, +1.13] | 是 |

負的 MAE 差代表模型比基準好。

| 模型 | 種子平均 MAE | 種子標準差 | 數值規則穩定通過 | 三種子皆具清楚統計優勢 |
| --- | ---: | ---: | --- | --- |
| Transformer | 48.99 | 0.13 | 是 | 否 |
| TFT-style | 48.97 | 0.27 | 否 | 否 |

## 結論

Transformer 三個種子的 MAE 均低於 49.22，因此依預先定義的數值規則通過；TFT-style 的種子 42 為 49.25，因此未穩定通過。

但 Transformer 的改善只有 0.09 至 0.39 元，所有 95% 信賴區間都跨過零；TFT-style 亦相同。這表示目前沒有足夠證據宣稱任一深度模型明顯優於最後收盤基準。最準確的說法是：**Transformer 在本次篩選中數值一致略勝基準，但優勢很小且統計上不明確。**

## 下一步門檻

不應立刻增加更多模型。較合理的下一步是擴增評分區間，或改進能產生實質差距的特徵，再要求改善的95%信賴區間上界低於零；否則增加 epochs 只會提高成本，未必提高可信度。

## 重跑

```powershell
python scripts/rolling_model_backtest.py --periods 20 --seeds 11,42,97 --models transformer,tft --epochs 4 --refit-epochs 2 --d-model 32
```

執行時會在 `artifacts/` 保存每次預測、實際值、截止日、MAE、RMSE與執行時間，並支援中斷後續跑。
