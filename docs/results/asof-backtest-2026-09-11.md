# TSMC 2026-09-11 截止四日封存回測

## 測試問題

如果在 2026-09-11（星期五）收盤後，只能使用當時已知資料，Transformer 與 TFT-style 模型對 2026-09-14 至 2026-09-17 四個交易日的直接多步預測表現如何？

這是可重跑的研究測試，不是投資建議，也不是交易績效。

## 防止偷看未來的設計

1. 先下載並驗證 2020-01-01 至 2026-09-11 的調整後 OHLCV。
2. 技術特徵只向前填補，不把未來值回填至過去。
3. 標準化器只在訓練分割擬合。
4. 訓練、驗證、測試的多步目標區間以三個樣本的 purge gap 隔離，避免四日標籤跨越分割邊界。
5. 完成模型預測後，程式才下載 09-14 至 09-17 的實際資料進行評分。
6. 歷史評估完成後，未來預測模型使用截止日前全部 1,252 個可用監督樣本再訓練六輪；仍不包含四個待預測日。

## 設定

| 項目 | 數值 |
| --- | --- |

| Transformer 訓練 loss | Huber |
| checkpoint 選擇 | 截止日前驗證集 MAE 最低 |

模型以 Yahoo Finance 調整後價格訓練及計算誤差，以避免除息造成序列不連續；另列交易所原始收盤價供人工核對。

## 結論

TFT-style 的四日價格 MAE 與 RMSE 低於最後收盤不變基準，但 60 日線性趨勢又低於 TFT-style；Transformer 未勝過最後收盤基準。此結果沒有被用來回頭選擇 loss 或 checkpoint。這次測試能證明的是「封存、直接多步預測、以截止日前驗證集選模及事後評分流程可以重跑」，不能證明模型已有穩定預測能力或投資價值。

## 下一步

1. 將 Transformer 與 TFT-style 放入已建立的 20 個互不重疊 rolling-origin 區間，目標是穩定勝過最後收盤基準 MAE 49.22。
2. 每個模型使用多個隨機種子，報告平均值、標準差與信賴區間。
3. 根據多期間驗證結果選擇模型，不依單一四日排名決策。
4. 保存模型權重、scaler、資料版本與套件版本，形成可部署實驗產物。
5. 若要討論策略，必須另外加入交易成本、滑價與風險指標。
