# 股價分析工具：第一次看懂操作與成果

這個專題將行情資料處理、模型訓練和圖表展示放到同一個網頁流程。對初學者而言，可以把它理解為「設定分析條件 → 取得資料 → 訓練模型 → 查看預測與真實值差異 → 保存實驗」的資料分析工具，不是自動下單機器人。

## 2. 三個常見參數先弄懂

| 名稱 | 白話意思 | 初次操作提醒 |
| --- | --- | --- |
| Window | 每次送給模型的一段過去資料有多長 | 資料太少、視窗太長，可能無法建立足夠樣本 |
| Horizon | 模型設定要預測多遠之後的目標 | 是模型資料步數／交易資料的設定，不宜直接當作日曆天 |
| Epochs | 訓練資料被模型反覆學習的輪數 | 增加不保證更準，可能更慢或過度配合訓練資料 |

Transformer 與 TFT-style 是此專案提供的兩種模型路徑；TFT-style 表示專案中的實作風格，未證明與原始 TFT 論文完全等價。此處不用先背模型原理，先確認自己選了哪一個模型、用了什麼資料、輸出代表什麼。

## 3. 第一次從網頁操作

先依 [README 本機啟動](../README.md#本機啟動) 安裝環境並開啟 `http://127.0.0.1:5000`。倉庫目前尚未提供經乾淨環境驗證的鎖定依賴；下面是依既有程式整理的操作路徑，不宣稱本次已重新完成安裝與訓練聯測。

| 順序 | 做什麼 | 期待看到什麼／卡住時檢查 |
| --- | --- | --- |
| 1 | 確認股票代號，例如預設 `2330.TW`，設定資料日期 | 日期範圍要合理，資料來源需要網路且可能暫時失效 |
| 2 | 按 `Fetch` | 先確認行情能取得，再進行訓練；無資料時不要直接反覆按訓練 |
| 3 | 設定 Window、Horizon、Epochs | 選用 Preset 會覆寫部分設定；保存前再次確認實際值 |
| 4 | 選 `Train Transformer` 或 `Train TFT` | 先跑單一模型理解流程；CPU 訓練需要等待，不能以網頁暫無更新判定完成 |
| 5 | 查看曲線與診斷 | 比較真實值與預測值，也檢查是否存在延遲、急跌時的大誤差 |
| 6 | 使用儲存功能保存實驗 | 留下參數、結果與日期，方便之後追查 |
| 7 | 從既有 Run 選取並讀取 | 展示已保存結果；這一步不會重新訓練，也不是取得今日新預測 |

`Train Both & Compare` 是依序訓練兩個模型，不是同時平行執行。某些診斷圖要看該次實驗是否保存對應欄位，不能期待所有舊 Run 都有完全相同的內容。

## 4. 如何解釋誤差，不把它說成準確率

上述歷史結果的 MAE 約 **21.633**、RMSE 約 **29.891**，是對保存陣列重新核算的數值。

| 指標 | 白話意思 | 不代表什麼 |
| --- | --- | --- |
| MAE | 每筆預測與真實值的絕對差取平均 | 不是「準確率 21.633%」 |
| RMSE | 先平方誤差再平均、開根號，較受大誤差影響 | 不是模型能賺多少錢 |
| 方向指標 | 保存結果對漲跌方向的分類表現 | 沒有交易成本與下單規則，不能轉述為報酬率 |

這兩個誤差值採用保存資料的價格尺度。資料切分與前處理仍需釐清，不能只挑漂亮數字作為已驗證的泛化能力。

## 5. 保存的資料能做什麼、不能做什麼？

| 資料 | 用途 |
| --- | --- |
| `config.json` | 回看模型與分析設定 |
| `y_true.npy`、`y_pred.npy` | 重繪已有曲線、重新計算誤差 |
| `test_dates.json` | 對應結果的日期標籤 |
| `metrics.json`、`diagnostics.json` | 回看該次保存的誤差與診斷 |
| `split_info.json` | 追查資料切分，但必須與設定、日期一起核對 |

目前核對的舊 Run 沒有完整的 `model.pt` 與 scaler。可以展示保存曲線，不表示這些資料足以恢復模型並對新行情推論。載入 Run 也不表示整個網頁都可離線使用，其他行情流程仍可能存取網路。

## 6. 備審適合強調什麼？

本作品適合呈現：用 Python 處理時間序列、將模型與 Flask 網頁串接、設計可調整參數、保存實驗及解釋圖表。林琨茂個人發想與製作，開發過程大量使用 AI 協助；並非宣稱自行提出 Transformer 或 TFT 新架構。

展示時應同時說明尚待改善的地方：訓練區間以外的資料不能拿來擬合前處理、需檢查 `bfill` 與日期對齊、需要可重現環境與獨立時段驗證。這是研究與工程原型，不提供買賣建議，也沒有券商下單功能。
